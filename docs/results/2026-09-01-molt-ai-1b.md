# MOLT AI 1B TinyStories v1

## Registered objective

Train a real dense GPT-style model with at least one billion unique parameters
on the user-supplied TinyStories file, persist a validated checkpoint, measure
held-out quality, and test generation from that exact checkpoint. This is a
prototype gate, not a useful-chatbot gate.

## Configuration and data

- 20 decoder blocks, width 2,048, 16 attention heads, MLP ratio 4
- 1,008,742,400 unique trainable parameters; BF16; activation checkpointing
- context 512, micro-batch one, stateless SGD at 0.01, seed 1337
- 17,500,000-byte training split, SHA-256
  `b6f92f21665663307311f5d0c181b9638989647402a82853860824d3996a07f0`
- 1,900,000-byte held-out split, SHA-256
  `09525ad8d658a5038a636be3e8c1c891f524d8b23d84b44e741bd79b92f098a6`

## Result

The run completed 1,024 updates and 524,288 training bytes in 302.229 seconds,
including 27.833 seconds of checkpoint I/O. End-to-end throughput was 1,734.736
bytes/s; peak PyTorch allocation was 4.082 GB, peak device-wide usage was 5.890
GB, minimum available system RAM was 3.531 GB, and sampled GPU board energy was
20,840.277 J. Validation improved monotonically from 9.02877 to 4.15462
bits/byte.

The 2,017,580,607-byte checkpoint hash is
`6999e705cf800f6a834c10327b476ac512a20dda7c50b3281751666a8b3fba85`.
The previous checkpoint is retained for recovery. GPU temperature observed
during manual monitoring reached 90°C and throughput declined from roughly
2,100 to 1,700 bytes/s, consistent with a thermal confounder; temperature is not
yet captured by the telemetry schema.

## Generation test

The exact checkpoint generated byte fragments resembling English character
frequencies but no coherent story. It failed to answer that Roxy used “big
leaves” to climb the icy hill. Therefore the checkpoint learned measurable
held-out statistics but is not a useful language or question-answering model.
It processed only 524,288 bytes—about 2.7% of the source file—once sampled, an
extremely small budget for random 1B pretraining.

Decision: accept the end-to-end 1B training/generation infrastructure gate;
reject any claim that MOLT AI v1 is fully trained, GPT-equivalent, or useful.
