# 75-second launch demonstration

[Watch the 75-second MP4](molt-launch-demo-75s.mp4) and inspect the
[sanitized session log](session.log) or [machine-readable record](launch-demo.json).

The recording uses the real values from one completed local run: hardware and
runtime identity, two-step fit test, 20-update static-graph training, NVML and
PyTorch memory/energy telemetry, PEFT export, and deterministic adapter reload.
Local filesystem paths were removed before publication. The recording is an
edited 75-second presentation of the preserved log, not a claim that environment
installation or model download completes in 75 seconds.
