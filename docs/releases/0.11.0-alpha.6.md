# MOLT 0.11.0 Alpha 6

This launch-readiness release aligns public version information and adds a
complete, measured path from installation to adapter inference. It does not add
a new performance claim.

## Changes

- Added one pinned beginner recipe using Qwen2.5-0.5B-Instruct, a project-authored
  downloadable dataset, an exact static-graph training configuration, expected
  output, PEFT export, and adapter reload.
- Added a 75-second 1280×720 demonstration generated from a real completed run,
  with a sanitized text log and machine-readable measurement record.
- Consolidated software versions, model/data identities, batch/context geometry,
  seeds, baseline settings, quality checks, elapsed-time accounting, memory
  definition, and NVML energy integration on one reproduction page.
- Updated the launch announcement to consistently describe MOLT as
  source-available under PolyForm Shield 1.0.0.

## Public version state

GitHub, the PyPI package metadata, the PyPI badge, installation commands, package
constant, lock file, and this release tag identify `0.11.0a6`. Older page text
reported by search or web caches is not the live repository or PyPI JSON state.

## Evidence boundary

The beginner demonstration is a tiny single-machine workflow smoke test. The
benchmark figure remains the 0.11.0a3 diagnostic result and still fails the
official controlled-clock gate. Soup, larger-model endurance, and independent
reproduction remain open.
