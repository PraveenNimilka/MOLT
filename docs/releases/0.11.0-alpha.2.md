# MOLT 0.11.0 Alpha 2

This metadata-correction release aligns GitHub and PyPI presentation. It does
not change the training implementation or add a competitor-performance claim.

## Corrections

- Removed the historical MIT license file from the current source tree so
  automated license detection does not misidentify current MOLT source as MIT.
  Historical MIT grants remain available in the immutable revisions and package
  files where they were originally offered.
- Retained PolyForm Shield 1.0.0 as the current source and package license.
- Replaced the GitHub About description's inaccurate `zero-RAM` and predictive
  temperature claims with evidence-bounded language.
- Removed the unverified numerical Unsloth comparison from the README. The
  comparison is explicitly pending until its registered evidence gate passes.

## Verification

- No training source changed between 0.11.0a1 and 0.11.0a2.
- The complete local suite contains 286 tests.
- Wheel and source distribution metadata declare
  `LicenseRef-PolyForm-Shield-1.0.0`.
