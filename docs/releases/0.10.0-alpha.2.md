# MOLT 0.10.0 Alpha 2

This public-release hardening update keeps training semantics and the measured
endurance profile unchanged.

## Security and packaging

- Updated GitHub Actions to Node 24-compatible releases and pinned every action
  to an immutable commit.
- Added weekly dependency and workflow update checks.
- Added high-severity static analysis and installed-dependency auditing in CI.
- Restricted the source distribution to build-essential package files; research
  records, benchmarks, tests, configurations, and CI files remain in GitHub but
  are no longer duplicated into the PyPI source archive.
- Resolved `nvidia-smi.exe` to an absolute path before elevated clock operations.
- Repaired interactive CUDA setup in uv-created environments that do not include
  pip, and pinned the supported PyTorch version.
- Migrated stale `molt-ai-infrastructure` package metadata during repository setup.

## Documentation

- Made the published `moltengine` installation path primary.
- Removed a stale installation guide and obsolete internal cleanup report.
- Clarified the MIT copying and redistribution boundary.

## Verification

- Complete local suite: 283 tests passed.
- High-severity Bandit findings: zero.
- Installed dependency audit: no known vulnerabilities; the CUDA-local PyTorch
  build is not represented in PyPI's vulnerability index.
- Wheel and source distribution metadata: passed `twine check`.

This is still an alpha research release. The benchmark evidence remains
single-machine and single-seed, not an official matched victory over Unsloth.
