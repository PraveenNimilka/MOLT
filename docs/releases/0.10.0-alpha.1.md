# MOLT 0.10.0 Alpha 1

This packaging release changes the Python distribution name from
`molt-ai-infrastructure` to `moltengine`. The user-facing command remains `molt`,
and the Python import package remains `molt_stream`.

It also adds secure PyPI Trusted Publishing, verified project metadata, and the
PEP 561 `py.typed` marker. Runtime training behavior and the verified endurance
measurements are unchanged from 0.10.0 Alpha 0.

## Verification

- Complete local test suite: 280 passed.
- Wheel and source distribution: built successfully.
- Distribution metadata: passed `twine check`.
- Wheel contents: no private artifacts or prepared datasets.

The benchmark results remain single-machine and single-seed evidence. They are
not an official matched victory over Unsloth and do not establish algorithmic
novelty.
