# MOLT 0.11.0 Alpha 1

This release changes the license for newly published source, adds a guarded
iso-clock reproduction screen, and formalizes the hardware-constrained PEFT
evidence boundary. It does not introduce a verified competitor-win claim.

## Reproducibility

- Added `benchmarks/reproduce_isoclock.py` for a matched, single-seed, 16-update
  MOLT/Unsloth screen with 100 ms NVML telemetry.
- Added non-mutating CUDA, path, geometry, administration, and VRAM preflight checks.
- Required explicit confirmation before graphics-clock mutation and unconditional
  automatic-clock restoration after every benchmark arm.
- Added measured clock-range, parameter-count, thermal-boundary, and held-out-NLL
  validity checks.
- Added a formal technical report separating the verified one-hour MOLT result
  from the incomplete competitor experiment.

## Licensing

- Source first published from the 0.11 development line is under PolyForm Shield
  1.0.0 and is source-available rather than OSI open source.
- Historical revisions through `a612b40734258b6ee0f1bea5777c7659a352dbee`
  and the PyPI `0.10.0a1` files remain under their existing MIT grant.

  notices follow it.

## Evidence boundary

The supplied `+37%` comparison cannot be reconstructed from checked repository
artifacts. It is not presented as verified in the README, technical report, or
launch draft. The verified endurance result remains single-machine and single-seed.
