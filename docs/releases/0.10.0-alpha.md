# MOLT 0.10.0 Alpha

This research-alpha release adds an explicit, reversible GPU endurance profile,
exact QLoRA loss/thermal instrumentation, expanded data interchange, and the
measured all-layer Qwen2.5-1.5B endurance record.

## Verified local result

One Windows 11 / RTX 4060 Laptop GPU run processed 4,915,200 tokens in 3,725.7
seconds (1,319.3 end-to-end tokens/s), peaked at 71 C, retained 97.3% late/early
throughput, consumed 0.03625 J/token of sampled GPU board energy, discarded no
updates, and improved held-out NLL from 1.6635 to 1.1045. This is explicitly a
single-machine, single-seed result and not an official competitor comparison.

## GPU profile safety

`molt optimize-gpu --profile endurance --config CONFIG` requires Administrator
access and explicit confirmation, applies the 1,500-1,650 MHz graphics-clock
range only for the child training operation, restores automatic clocks in all
exit paths, and verifies the range recorded by telemetry. Laptop power limits
are not modified.

## Release boundary

MOLT remains an open-source research alpha without a support SLA. Multi-seed
AB/BA comparison, independent reproduction, fresh-machine installation, broader
model coverage, and extended security review remain open gates.

Release verification: 280 automated tests passed; wheel and source distributions
built; an isolated wheel installed and launched `molt doctor`; dependency audit
reported no known vulnerabilities, while the local package and CUDA-specific
Torch build were outside the audit database.
