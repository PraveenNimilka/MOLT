# MOLT 0.11.0 Alpha 7

This release carries forward the launch-readiness material from Alpha 6 and
fixes its Windows checkout integrity failure. Alpha 6 was tagged on GitHub, but
its hosted tests failed before PyPI publication; it is superseded by Alpha 7.

## Changes

- Declared JSON Lines and public text logs as LF-normalized repository assets so
  their documented SHA-256 values remain identical on Windows and Linux.
- Declared MP4 demonstrations as binary assets.
- Retained the pinned beginner recipe, measured 75-second demonstration, public
  logs, and consolidated diagnostic reproduction page introduced with Alpha 6.
- Kept launch language consistent: MOLT is source-available under PolyForm
  Shield 1.0.0.

## Evidence boundary

This release fixes packaging and reproducibility infrastructure. It does not add
a performance claim. The published diagnostic comparisons remain uncontrolled-
clock evidence; Soup comparison, larger-model endurance, and independent
reproduction remain open.
