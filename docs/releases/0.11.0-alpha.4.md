# MOLT 0.11.0 Alpha 4

This is a documentation and packaging release. Training behavior is unchanged
from 0.11.0a3; no new performance result is claimed.

## Changes

- Simplified the README title and release wording; the PyPI badge and install
  examples now explicitly identify this release.
- Published the licensing and attribution improvements previously on `main`:
  SPDX-compatible license metadata, NOTICE, third-party attribution, and
  trademark/fork guidance. PolyForm Shield 1.0.0 remains the license.
- Included updated security reporting and contribution guidance, with critical
  Python lint checks in CI.
- Published the existing a3 diagnostic benchmark figure, aggregate data,
  calculation method, and deterministic renderer. The README image uses a
  release-pinned absolute URL so it also works on PyPI.

## Evidence boundary

The displayed benchmark remains the 0.11.0a3 diagnostic screen, not a new a4
measurement. Controlled comparisons, Soup, larger-model endurance, and
independent reproduction remain open. Validate your workload before production
use.

## Installation

Follow the [installation guide](../../README.md#requirements) for Windows,
Python 3.12, NVIDIA/CUDA prerequisites, and the pinned 0.11.0a4 install command.

Release publishing runs automated tests, builds the wheel and source archive,
checks their metadata, and uploads through PyPI trusted publishing.
