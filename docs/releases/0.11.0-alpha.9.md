# MOLT 0.11.0 Alpha 9

Alpha 9 supersedes Alpha 8 for the managed Windows installation path. It keeps
the shared runtime, reusable CUDA package cache, PATH conflict reporting, and
`molt update`, `molt repair`, and `molt uninstall` commands introduced in Alpha
8, while correcting Windows executable locking during in-place repair and
update.

## Correctness fix

- `molt update` and `molt repair` move the running console executable aside
  before replacing packages, restore it if package installation fails, and
  remove the retired executable with bounded background retries.
- `molt uninstall` uses bounded background retries when Windows temporarily
  retains a handle to runtime files.
- Installer verification still requires dependency consistency, a CUDA
  backward pass, and the compiled-backward probe.

## Release boundary

This is an installation and runtime-management release. It does not alter the
training engine and makes no new benchmark claim. The published Alpha 3
comparison remains diagnostic evidence; controlled-clock comparisons, a Soup
comparison, larger-model endurance, and independent reproduction remain open.

MOLT remains a source-available research alpha under PolyForm Shield 1.0.0.
