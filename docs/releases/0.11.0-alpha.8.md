# MOLT 0.11.0 Alpha 8

Alpha 8 replaces per-project beginner environments with one verified per-user
Windows runtime. It does not add or revise a performance claim.

## Changes

- Added a public one-command PowerShell installer that provisions Python 3.12,
  explicitly selects CUDA 12.8 PyTorch, installs all supported training extras,
  and fails closed on dependency, CUDA, or compiled-backward verification.
- Standardized the runtime at `%LOCALAPPDATA%\MOLT\runtime` and launcher at
  `%LOCALAPPDATA%\MOLT\bin\molt.cmd`.
- Added a persistent uv package cache so large CUDA packages are reused across
  projects and repairs.
- Added functional `molt update`, `molt repair`, and `molt uninstall` commands.
- Made the managed launcher first in the user PATH and report lower-priority
  conflicting launchers without deleting unrelated Python environments.
- Updated the beginner and installation documentation. `winget install MOLT`
  remains a future distribution target pending a versioned binary package and
  acceptance into Microsoft's package index.

## Evidence boundary

The a3 benchmark figure remains historical diagnostic evidence. Alpha 8 changes
installation and runtime management only. A new controlled Alpha 8 comparison
must pass before the benchmark figure is replaced.
