# MOLT 0.11.0 Alpha 5

This release makes first-time setup, guided training, thermal visibility, and
safe interruption substantially simpler. It does not introduce a new public
performance claim.

## Changes

- Added `molt setup` to install and validate the supported CUDA, QLoRA, data,
  Windows monitoring, and optimized-kernel runtime after the base PyPI install.
- Reworked bare `molt` into a keyboard-driven guided workflow that asks for the
  model and dataset, prepares supported raw data, recommends important training
  settings, runs a short fit check, and then starts the full run.
- Added stable-start cooling for GPU and CPU thresholds. CPU package temperature
  is displayed and recorded only when the operating system or a supported
  hardware monitor supplies a trustworthy sensor.
- Added safe Ctrl+C handling at an optimizer-update boundary, including explicit
  choices to continue, stop, and save a verified resumable checkpoint.
- Extended telemetry summaries with CPU temperature source, mean, and peak when
  available, while preserving the existing GPU thermal safety boundary.
- Restored the matched-comparison harness contract used by the release tests,
  including AB/BA trial ordering, protocol hashes, cold-start checks, and
  power-envelope validation.
- Added direct dependency metadata and third-party attribution for runtime
  version checks and optional Windows CPU monitoring.

## Evidence boundary

The benchmark figure in the README remains the 0.11.0a3 diagnostic result. This
release changes product workflow and measurement plumbing; it does not establish
a new speed, memory, energy, or quality advantage. Validate your own workload
before production use.

## Installation

Create and activate a Python 3.12 environment, then run:

```powershell
python -m pip install moltengine==0.11.0a5
molt setup
molt doctor
molt
```

Release publishing runs automated tests, builds the wheel and source archive,
checks their metadata, and uploads through PyPI trusted publishing.
