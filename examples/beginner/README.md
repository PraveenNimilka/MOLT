# Beginner quickstart files

These files support the pinned beginner recipe in
[`docs/BEGINNER_QUICKSTART.md`](../../docs/BEGINNER_QUICKSTART.md).

- `molt-demo.jsonl` is a deliberately small, project-authored demonstration
  dataset distributed under MOLT's repository license.
- `configure.py` turns MOLT's generated starter file into the exact 20-update
  demonstration configuration.
- `reload_adapter.py` loads the exported PEFT adapter with its local base model
  and performs deterministic inference.

The sample proves the install, prepare, train, export, and reload path. It is
not an evaluation of useful model quality.
