# Support

MOLT is a source-available research alpha without a commercial support SLA.

- Use GitHub Issues for reproducible defects and documentation problems.
- Use GitHub private security advisories for vulnerabilities.
- Include `molt --json doctor`, the MOLT version or commit, relevant configuration,
  and the smallest safe reproduction.
- Remove credentials, private data, model weights, and sensitive paths.

General performance questions must include the model, data geometry, optimizer,
precision, hardware, thermal state, measurement window, and quality objective.
Unmatched throughput numbers are not accepted as comparative evidence.
